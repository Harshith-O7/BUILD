The Construction Site Management Dashboard is a modern web application designed to simplify construction site operations. It helps construction companies, civil engineers, contractors and project managers manage multiple construction activities through a single platform.

The application provides features such as project progress tracking, workforce attendance, equipment management, material inventory, budget monitoring, safety management and daily site reports. It helps users monitor key performance indicators, including project completion percentage, employee attendance, material stock levels, equipment utilization, daily expenses and budget variations. These measurable indicators make it easier to identify delays, track resource usage and monitor project performance.

Built using React.js, TypeScript, Tailwind CSS, Firebase and Recharts, this project aims to reduce manual record-keeping and improve construction management. Its measurable goals include better visibility into project progress, more organized inventory tracking, improved expense monitoring and faster access to daily site information.
